## 📦 Instalação — Passo a Passo

### 1️⃣ Instale a extensão no seu Bot

1. Na tela principal do Blip, clique em **Blip Store** (ao lado de "Home")
2. No menu lateral, selecione **Extensões**
3. Procure por **"Connect Team"**
4. Clique em **Ativar** — ⚠️ *instale obrigatoriamente no seu bot **Router/Roteador***

---

### 2️⃣ Ative a extensão

Após a instalação, clique em **"Ativar Extensão / Atualizar"** conforme indicado na tela abaixo:

![Tela de ativação da extensão](https://github.com/user-attachments/assets/29b5c152-f8c4-4021-be42-db3e2de57807)

> 💡 **Dica:** Sempre que houver uma atualização da extensão, repita este passo para garantir acesso às novidades.

---

### 3️⃣ Instale no Chrome de cada atendente

Após ativar, um link de instalação será exibido na tela de configuração. Clique no link para instalar a extensão no Google Chrome:

![Link de instalação no Chrome](https://github.com/user-attachments/assets/1b5ed5fd-9522-48e9-ba2d-eefa23656c9c)

Em seguida, confirme a instalação diretamente no Chrome:

![Confirmação da instalação no Chrome](https://github.com/user-attachments/assets/b9fe007a-3e27-4afd-9c43-4edc167b30af)

## ❓ Perguntas Frequentes

**Preciso instalar em cada computador?**  
Sim. A extensão do Chrome precisa ser instalada no navegador de **cada atendente**.

**O histórico fica salvo para sempre?**  
Sim.

**Qualquer pessoa pode excluir um grupo?**  
Não. Somente o **criador do grupo** pode excluí-lo.

**Funciona em outros navegadores além do Chrome?**  
A extensão foi desenvolvida para o **Google Chrome**. Outros navegadores não são suportados oficialmente.

**Posso usar no bot de atendimento direto (não roteador)?**  
Não. A extensão deve ser instalada exclusivamente no **bot Router/Roteador**.
